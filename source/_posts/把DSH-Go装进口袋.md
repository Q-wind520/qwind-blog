用了一段时间，越用越觉得值得单独写一篇。不是那种"手机上也能写代码了！"的猎奇，而是它确实把我以前在手机上干不成的事，变得没什么障碍了。

## 以前在手机上干活，止步于"能跑"

Termux 那套我折腾过：proot-distro 装 Ubuntu、换源、装 node、处理后台被杀、锁屏断连、软键盘把终端挡掉一半……能跑，但谈不上好用，每次都要重新对付一遍环境。

DSH Go 把这些一次性收进了 App 里：内嵌一套 arm64 的 Ubuntu（proot 跑），node、git、python 都齐，外面套一层 Flutter 原生界面，对话、文件、终端、后台任务都有正经入口。装完打开，等运行时就绪，就是一个能干活的环境——不用先当半小时系统管理员。

## 界面是真的下了功夫

这点是我最想夸的。

毛玻璃、圆角、克制的动效，整体是那种"轻但不飘"的手感。切换模式的时候尤其明显：元素不是硬切，而是带一点模糊和位移地过渡过去，视觉上很顺（这篇的封面就是正好截到过渡中的一帧，糊得很自然）。

抽屉里是会话列表，带「全部 / 运行中 / 待确认 / 未读」筛选，找会话不用翻：

![抽屉：会话列表与筛选](/img/dsh-go/drawer.jpg)

每轮对话还能点开「信息」，用时、步骤数、改动文件数一目了然：

![信息面板：用时、步骤、改动文件](/img/dsh-go/info.jpg)

「共 2 轮 / 4:41 / 37 步 / 1 个改动文件」——这种统计别的工具要么没有，要么得自己数。

「全部功能」页把网页版的能力都摆了出来，不是藏在一堆菜单里：

![全部功能](/img/dsh-go/features.jpg)

## 拿它管项目，是真的能管

今晚这篇就是证据。整个过程在手机上一个对话里完成：

```bash
gh repo clone Q-wind520/qwind-blog
# 写文章、放截图
git commit -am "post: ..."
git push
```

顺手还给 DSH Go 自己提了个 issue：

```bash
gh issue create --repo ccch1mneyyy/dsh-Go \
  --title "..." --body-file issue.md
```

关键在于它没有"手机特供"的阉割：工作区就是普通目录，git 就是普通 git，`gh` 登录一次就能一直用。clone、改、提交、推送，和在电脑上没区别，只是屏幕小一点。

## 顺带的小插曲

语音输入没识别出来时，底部弹出的提示条会压住输入框几秒，想重试得等它消失。已经提了 [#1454](https://github.com/ccch1mneyyy/dsh-Go/issues/1454)，也顺手把定位和修改方向写进去了。

![语音提示条压住输入框](/img/dsh-go/voice-toast.jpg)

小毛病，不影响上面的结论，但确实值得修。

## 还有它自己的样子

「伙伴小屋」可以放一个像素小人（也支持 Live2D），站在角落陪着，素材在手机上导入就行：

![把她接回家](/img/dsh-go/companion.jpg)

工具归工具，这种小设计我倒不排斥——一个每天要开很多次的东西，顺眼一点很重要。

## 适合谁

- 想随时随地改两行、跑个命令、看个构建结果的人；
- 不想再跟 Termux 的环境搏斗的人；
- 愿意让 AI 直接在自己手机上干活的人。

如果是长时间的重度开发，桌面端还是更顺手。但"临时要干点活"这个场景，我现在第一反应是掏手机。
