## 制作过程

### 准备镜像和工具

**Windows重装：** Windows 11 镜像、WinPE 盘（我用FirPE）
**Pop!_OS安装：** Pop!_OS 镜像
**其他可选工具：** Ventoy（推荐，用一枚 U 盘同时放入两个系统镜像，开机自选启动项，无需反复烧录）

**硬件要求：** 一块大于 240GB 的硬盘（内置，512GB 体验更从容）、一枚大于 16GB 的 U 盘、用于备份数据的存储器

### 备份

将 Windows 中的重要文件导出到备份硬盘。存在大量小文件时，建议使用 Windows 内置的 `robocopy` 复制工具（用法：`robocopy 源目录 目标目录 /E`；`/E` 表示连同空子目录一并复制。注意退出码：小于 8 均属正常，大于等于 8 才表示有文件复制失败）

### 重装Windows

**制作启动盘：**
1. 下载 Windows 11 镜像
2. 使用 Ventoy 制作启动 U 盘

**重装前：**
1. 备份重要数据（方法见上文"备份"一节）
2. 导出驱动（网卡驱动尤其重要，否则装完新系统可能无法联网），两种方式任选：
   - 在旧 Windows 中：管理员运行命令提示符，执行 `dism /online /export-driver /destination:E:\drivers`（把 `E:` 换成数据分区或备份硬盘盘符）
   - 或进入 PE 后：用 FirPE 内置的图形化驱动导出工具，把驱动导出到数据分区
   - 导出目录放在不会被重装波及的盘上即可

**重装步骤：**
1. 开机按启动菜单键（F12 / F11 / F7，视主板而定），**以 UEFI 模式**选择 U 盘进入 PE 系统
2. 在 PE 中启动 Windows 安装程序，选择"自定义安装"
3. 删除原有全部分区，建议只给 Windows 建一个系统分区（约占硬盘一半），**其余空间保持"未分配"，留给稍后的 Pop!_OS**
4. 完成 Windows 安装
5. 导入驱动：用设备管理器"更新驱动"→"浏览我的电脑"指向导出驱动时的目录（如 `E:\drivers`），或直接双击其中的 inf 文件
6. 进入 Windows 系统完成使用引导（OOBE），到此先别动磁盘

### 十分重要的设置

**1. BitLocker 解锁：**
- 打开"设置" → "隐私和安全性" → "设备加密"，若状态为"已开启"则将其关闭（解密需等待一段时间）
- 或使用管理员命令行：`manage-bde -off C:`
- 为什么要关：BitLocker 会把 NTFS 分区加密，Linux 侧无法解密读取，装好 Pop!_OS 后将完全看不到 Windows 的文件

**2. 快速启动 关闭：**
- 打开"控制面板" → "硬件和声音" → "电源选项" → "选择电源按钮的功能"
- 点击"更改当前不可用的设置"
- 取消勾选"启用快速启动（推荐）"
- 保存修改
- 为什么要关：快速启动会让 Windows"关机"时并不真正关闭系统，而是进入休眠状态，NTFS 分区处于锁定挂起状态——Linux 会拒绝挂载，强行挂载可能导致数据损坏

**3. 安全启动 关闭：**
- 进入 BIOS/UEFI 设置（开机时按 F2 / Del 等）
- 找到 "Secure Boot" 选项并禁用
- 不同主板位置不同，参考主板说明书
- 为什么要关：Pop!_OS 官方不支持 Secure Boot，不关闭将无法引导。注意此步应在 Windows 安装完成后再进行（Windows 11 安装程序要求 Secure Boot 处于启用状态）

**磁盘分区：**
- 若在重装 Windows 时已预留"未分配"空间，此步直接跳过即可
- 若没预留：打开"磁盘管理"（右键开始菜单 → 磁盘管理），右键 C 盘 → "压缩卷"，输入要分配给 Pop!_OS 的空间大小（建议至少 100GB）
- 压缩卷只能挤出"分区末尾没有文件占用的连续空间"，实际可压缩量受文件分布影响，若压不出理想大小，可用 DiskGenius 等工具无损调整分区
- 压缩后产生的"未分配"空间**不要新建任何分区**，保持原样交给下一步

### 安装Pop!_OS

**制作启动盘：**
1. 下载 Pop!_OS 镜像（System76 官网，x86_64 版本约 2.6GB）
2. 使用 Ventoy 或 Etcher 制作启动 U 盘（与 Windows 启动盘共用一枚 Ventoy U 盘即可）

**安装步骤：**
1. 开机以 UEFI 模式从 U 盘启动，进入 Pop!_OS Live 系统
2. 选择 "Try or Install Pop!_OS"
3. 跟随安装程序完成语言、键盘等配置
4. 选择 "Custom（Advanced）" 高级安装选项
5. 点击左下角 "GParted" 按钮打开磁盘分区工具
6. 选中先前留下的"未分配"空间，新建两个分区：
   - **EFI 引导分区：** 约 1GB，文件系统选 **fat32**，创建后右键 → "Manage Flags" 勾选 **boot、esp** 两个标志（这是能否引导的关键，漏了必定无法开机）
   - **根分区（/）：** 剩余全部空间，文件系统选 **ext4**
   - 两个分区前后各留 2MB 空闲是 GParted 默认的分区对齐间距，无需刻意手动留白
7. 点击绿色勾号应用改动
8. 返回安装程序点击"取消"，再重新进入 "Custom" 刷新分区列表
9. 将 fat32 分区挂载为 **`/boot/efi`**，ext4 分区挂载为 **`/`**（Pop!_OS 安装器的挂载点下拉中有 /boot/efi 选项；若你自建的 fat32 分区带 boot 标志，它会成为 Pop!_OS 独立引导区，与 Windows 的引导互不干扰）
10. 继续完成后续配置（用户名、密码等）
11. 点击 "Install" 开始安装
12. 安装完成后点击 "Restart"，弹出提示时拔掉 U 盘

---

至此，双系统部署完成

## 常见问题

**Q: 重启后没有出现系统选择菜单？**
A: 正常现象。Pop!_OS 使用 systemd-boot 引导，且两个系统各自使用独立的引导分区，开机默认直接进入其中一个系统，不会出现 GRUB 那种二选一菜单（"按住 Shift 调出 GRUB"是 Ubuntu 的用法，对 Pop!_OS 不适用）。
- 切换系统：开机时按 F12（视主板而定）调出固件启动菜单，选 "Windows Boot Manager" 进 Windows、选 "Pop!_OS" 进 Pop
- 想让哪个系统作为默认：在 BIOS 启动顺序里把对应启动项调到第一位即可

**Q: Windows时间与Linux时间不同步？**
A: 在Windows中运行命令：`reg add "HKLM\SYSTEM\CurrentControlSet\Control\TimeZoneInformation" /v RealTimeIsUniversal /t REG_DWORD /d 1 /f`

**Q: NVIDIA显卡但安装的是非闭源驱动版本？**
A: 不用担心。说明你下载的是 Intel/AMD 通用版镜像，它默认只带开源的 nouveau 驱动（能用但性能差、还不支持 Wayland 加速）。补装 NVIDIA 闭源驱动：

```bash
sudo apt install system76-driver-nvidia
```

安装完成后**重启**，再用 `nvidia-smi` 验证驱动是否生效即可。

我曾对 Linux 有一些向往，由于太难和没太多需要，长久以来只是在虚拟机玩玩，也没有真正部署到物理机。曾几何时，AI Agent 可以很好地操作电脑，于是我便开始了 Linux 桌面的探索，尝试了 Mint 和 Pop!_OS，我感到「欣喜若狂」！出于 Windows 打游戏的需要，随即我打算将我的 512GB 硬盘制成双系统（Pop!_OS & Windows）。

然而整个部署过程我踩了很多坑，我失去了很多耐心。最初我打算把 Windows 重装后迁移原来的 Pop!_OS 到硬盘新分区，由于自己对 Pop!_OS 这个系统乃至对 Linux 的分区并不了解，我将一部分工作全权交由 AI 解决。于是——啥子 AI 把我源系统数据删了……

回放：AI `dd` 从原系统 /home 分区逐字节复制到目标新分区（回头看其实从这里就错了），`dd` 超时了（数据量很大但 AI 加了个 timeout），一通分析，rsync 重新复制（没把目标分区数据清除），然后盘炸了，一看我质问它为什么不先清除原来的数据，然后让它清除原来的数据（此时我放弃了逐字节迁移），并且强调清除未分配分区的数据。嗯……我不知道它思考了啥，最后把我源分区也 rm 了。
